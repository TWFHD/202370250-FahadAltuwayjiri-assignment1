# Fahad Personal Portfolio

This is a simple personal portfolio website created for Assignment 1. It includes information about me, two project ideas, my current skills, and a contact form.

## Features

- About Me section
- Two project cards
- Contact form
- Smooth scrolling
- Responsive layout for desktop, tablet, and mobile

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a web browser.

ChatGPT was used to help explain the assignment, suggest a basic layout, and check the code and documentation. I reviewed the suggestions and will personalize and test the project before submission.
