# AI Usage Report

## Tool Used and How I Used It

I used ChatGPT while working on this assignment. I asked it to explain the assignment requirements, suggest a simple portfolio structure, and help me find problems in the HTML, CSS, and JavaScript. It also helped me organize the README and technical documentation.

## Benefits and Challenges

ChatGPT helped me get started and understand how to divide the website into sections. It also gave me examples of responsive design and JavaScript interactions.

One challenge was that some suggestions were more complicated than I needed. I also needed to check the output because AI suggestions can contain mistakes or information that does not match my project.

## What I Learned

I learned how to:

* Create sections and forms with HTML.
* Use Flexbox, Grid, and a media query in CSS.
* Select elements and respond to form events with JavaScript.
* Organize a project into separate folders and files.
* Test AI suggestions instead of accepting them without checking.

## Responsible Use and Changes

I used the AI output as a starting point. I review every file before submitting it. 

I understand that I am responsible for the final project and should be able to explain how the code works.
