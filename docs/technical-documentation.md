# Technical Documentation

## Project Description

This is a simple one-page portfolio website. It was created with HTML, CSS, and JavaScript without using a framework.

## Files

- `index.html`: contains the website content and sections.
- `css/styles.css`: contains the colors, spacing, layout, and responsive design.
- `js/script.js`: contains the greeting, form message, and current year.
- `assets/images`: contains the profile and project placeholder images.
- `docs`: contains the project documentation.

## Website Sections

1. **Home:** displays my name, introduction, and an image.
2. **About Me:** includes a short introduction, skills, and student information.
3. **Projects:** displays two of my projects .
4. **Contact:** contains Name, Email, and Message fields.

## Responsive Design

The website uses Flexbox for the navigation and hero section. CSS Grid is used for the project cards. A media query changes the layout to one column when the screen width is 700 pixels or less.

## JavaScript

The JavaScript file has three small functions:

- It changes the welcome message depending on the time.
- It displays a thank-you message after the contact form is submitted.
- It adds the current year to the footer.

## Testing

Before submission, I will:

- Open every section and test the navigation links.
- Resize the browser to check the mobile layout.
- Submit the form with valid and missing information.
- Check that the greeting changes correctly.
- Check the browser console for errors.

## Limitations

The contact form is only a demonstration and does not send information to a server. The project images are placeholders and can be replaced later.
